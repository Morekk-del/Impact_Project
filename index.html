Panduan Upload ke GitHub Pages

Anda dapat mempublikasikan dashboard web **IMPACT PROJECT** ini secara gratis agar bisa diakses seluruh anggota tim kelas melalui link GitHub Pages.

Langkah 1: Simpan File Dashboard

Simpan seluruh kode HTML ini ke dalam satu file bernama index.html di dalam folder baru komputer Anda.

Langkah 2: Inisialisasi Repository Git

Buka Terminal / Command Prompt di folder tersebut, lalu jalankan perintah:

git init
git add .
git commit -m "Initial commit - Impact Project Dashboard"
Langkah 3: Push ke Repository GitHub

Buat repo baru di github.com/new dengan nama impact-project, lalu hubungkan:

git branch -M main
git remote add origin https://github.com/USERNAME/impact-project.git
git push -u origin main
Langkah 4: Aktifkan GitHub Pages
  1. Buka halaman repository Anda di GitHub.
  2. Masuk ke menu Settings > Pages (di sidebar kiri).
  3. Pada bagian Build and deployment, atur Source ke Deploy from a branch.
  4. Pilih Branch: main dan folder / (root), lalu klik Save.
